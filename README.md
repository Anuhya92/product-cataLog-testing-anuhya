# Product Catalog & Favorites Summary

The application is an e-commerce shopping interface built with Next.js,and TypeScript, tested thoroughly with Jest and React Testing Library (RTL).

# Key Features Tested:
Dynamic Header & Badge: Real-time favorite item counter that updates as users select items.

Product Catalog: Lists available products with details, pricing, and category tags.

Availability Edge Cases: Gracefully handles out-of-stock items (disabling buttons) and empty store states.

Favorites Tray: An interactive Favourite  item summary where users can inspect their saved items or clear them all in one click.
